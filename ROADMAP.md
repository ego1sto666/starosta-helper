# План развития «Помощника старосты»

Цель: приложение не только для 26-ИВТ-2-1, а для любого старосты НГТУ (и других вузов): свой аккаунт,
своя группа, письма преподавателей — себе на экран, а не в общий доступ. Делаем **по шагам**: после каждого
шага приложение работает, тесты зелёные, отдельный коммит.

## Что уже сделано (без сервера, данные на устройстве)

- **Сегодня**: идёт сейчас / следующая пара, сроки, события, дни рождения, риск недопуска, сессия.
- **Журнал**: неделя, отметка в одно касание, переносы/отмены/разовые пары, автопроверка расписания НГТУ.
- **Группа**: студенты и преподаватели, подгруппы, академ и отчисление, фото, контакты из таблицы/.vcf.
- **Учёба**: сдачи работ, сессия, оценки и стипендия. **Внеучебка**: дела, сборы (деньги и документы), события, опросы.
- **Итоги**: графики посещаемости по неделям, дням и парам; выгрузка в Excel.
- Шаблоны сообщений, списки для чата столбиком, напоминания на ПК, PIN-код, копия данных, тёмная тема.
- Оформление 2.0: значки Phosphor, шрифты Onest и Unbounded, плавные переходы, тёмная боковая панель на ПК.

## Фундамент под сервер (готово 2026-11-06, не подключено)

- `server/` — API на FastAPI: аккаунты, группы, синхронизация, почта; 13 тестов проходят.
- `server/design/` — решения: архитектура, вход, почта, синхронизация, 152-ФЗ, автоматизация.
- `js/api.js` — клиент API и слияние изменений с двух устройств (тест `tests/sync-merge.html`); загружается приложением, но без адреса сервера не выполняет запросы.
- `prototypes/index.html` — макеты экранов «Вход», «Регистрация», «Подключение почты», «Почта».

Удалены пустой случайный DOCX, файл `.nojekyll` для отключённого GitHub Pages и неиспользуемый CSS-токен `--header-bg`.
В `tests/fixtures/demo.json` также заменены имена преподавателей; текущие отслеживаемые файлы проверены на ФИО из старого демо.
В `js/app.js` статический поиск не нашёл именованных функций без обращений. Старую миграцию `settings.semesters`
оставляем: она нужна для уже сохранённых данных пользователей.

**Перед публичным запуском:** предыдущие коммиты публичного репозитория всё ещё содержат старую версию
`demo/group.json` с настоящими ФИО. Замена в текущей версии не стирает историю Git. Нужна отдельная согласованная
очистка истории или новый чистый репозиторий, затем повторная проверка публичных файлов.

Текущие напоминания выполняются в `js/app.js` раз в минуту **только при открытом приложении**. В `sw.js` есть
обработка клика по уведомлению, но нет обработчика `push`; на сервере нет подписок и отправки Web Push.
Клиент `js/api.js` подключён; экраны аккаунта доступны, но отправка форм закрыта без сервера и ссылки на политику. Экран почты пока существует только как макет.
В серверном черновике ещё нет миграций, вложений, рабочей отправки сброса пароля и проверки IMAP при подключении.
Все эти пункты — задачи до реального запуска, а не уже работающие возможности.

### Шаг 2. Сервер в интернете
- [ ] Миграции Alembic вместо `create_all`.
- [ ] VPS: Docker, `server/.env`, `docker compose up -d`, HTTPS (Caddy), резервные копии базы.
- [ ] Проверка: `https://<домен>/api/health` → `{"ok": true}`.

### Шаг 3. Аккаунты в приложении
- [x] Подключить `js/api.js`, экраны «Вход» и «Регистрация» по макетам 1–2.

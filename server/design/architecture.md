# Как устроен «Помощник старосты» с сервером

Статус: **проект**. Сейчас приложение работает без сервера. Этот документ — план, по которому его добавляем
шаг за шагом (см. `ROADMAP.md` в корне), не ломая то, что уже есть.

## Главные принципы

1. **Сначала устройство.** Приложение (PWA) хранит данные в браузере и работает без интернета — как сейчас.
   Сервер — дополнение: копия данных, общий доступ с замом, письма преподавателей. Без аккаунта всё работает.
2. **Для любой группы.** Ничего не привязано к 26-ИВТ-2-1: у каждого старосты свой аккаунт, своя группа,
   свой адрес для писем, свои данные. Один староста не видит данные другого.
3. **Храним минимум.** Письма — только от преподавателей из списка группы и ограниченное время. Пароль от почты
   по возможности не храним вовсе (пересылка). Подробно — `privacy-152fz.md`.
4. **Шаги маленькие.** Каждый шаг — рабочее состояние, тесты, отдельный коммит.

## Схема

```
 Телефон / ПК старосты и зама                    Сервер в России (одна VPS, Docker)
 ┌──────────────────────────────┐   HTTPS   ┌────────────────────────────────────────────┐
 │ PWA (index.html, js/app.js)  │ ────────► │ Caddy: HTTPS, отдаёт PWA, /api → API        │
 │  • данные в localStorage     │           │ API (FastAPI, server/app)                  │
 │  • js/api.js — вход, синхр., │ ◄──────── │  • /auth   аккаунты, вход, сброс пароля     │
 │    «Почта»                   │  cookie   │  • /groups группы, данные, приглашения     │
 └──────────────────────────────┘           │  • /groups/{id}/inbox  предложения из писем │
                                            │ PostgreSQL — аккаунты, данные групп, письма │
 Почта старосты (Яндекс/Mail.ru/Gmail)      │ worker — IMAP-ящики, очистка, напоминания   │
  правило «от преподавателей → переслать» ─►│ inbound — приём писем на адрес группы (25)  │
                                            └────────────────────────────────────────────┘
```

## Из чего сделано и почему

| Часть | Выбор | Почему |
|---|---|---|
| Сервер | Python 3.12 + FastAPI | Пользователь знает Python (прежняя версия на Kivy); FastAPI сам строит документацию API (`/docs`) |
| База | PostgreSQL 16 (локально — SQLite) | Надёжно, JSON-поля для данных группы, бесплатно |
| Таблицы | SQLAlchemy 2 + Alembic (миграции) | Один код для SQLite и PostgreSQL |
| Пароли | Argon2id (`argon2-cffi`) | Рекомендация OWASP для хранения паролей |
| Секреты почты | Fernet (`cryptography`), ключ — в переменной окружения | Пароль приложения не лежит в базе открытым текстом |
| Вход | cookie `httpOnly` + `SameSite=Lax` + заголовок `X-Starosta` | Токен не украсть скриптом со страницы, чужой сайт не подделает запрос |
| Письма | Пересылка на адрес группы (aiosmtpd), позже IMAP | Пароль почты не нужен; приходит только то, что выбрал староста (`mail.md`) |
| Хостинг | VPS в России (Timeweb Cloud, Selectel, Yandex Cloud) | 152-ФЗ: персональные данные граждан РФ — в базах на территории РФ |
| HTTPS | Caddy | Сертификат Let's Encrypt получает и продлевает сам |
| Запуск | `docker compose up -d` (`server/docker-compose.yml`) | Всё одной командой, легко перенести |

Примерная стоимость: VPS 1–2 ГБ — 300–600 ₽/мес, домен `.ru` — ~200 ₽/год. Для старта хватит одной машины.

## Что где лежит

```
server/
  app/main.py           — API: подключение маршрутов, CORS, защита от подделки запросов
  app/routers/auth.py   — регистрация, вход, выход, сброс пароля
  app/routers/groups.py — группы, синхронизация data.json, приглашения замов
  app/routers/mail.py   — источники почты, экран «Почта»
  app/mail/parse.py     — разбор письма: преподаватель?, даты, тип (без внешних библиотек)
  app/mail/service.py   — приём письма: фильтр → сохранение → предложение
  app/mail/inbound.py   — приём пересланных писем (SMTP)
  app/mail/imap.py      — чтение ящика по IMAP
  app/worker.py         — фоновые задачи
  app/models.py         — таблицы; schema.sql и openapi.json выгружаются из кода (tools/export_contract.py)
  tests/                — test_parse.py (без библиотек), test_api.py (весь сценарий)
  design/               — решения: этот файл, auth, mail, sync, privacy-152fz, automation
js/api.js               — клиент API и слияние изменений (в приложение ещё не подключён)
prototypes/index.html   — макеты экранов «Вход», «Регистрация», «Подключение почты», «Почта»
```

## Как приложение узнаёт о сервере

`js/api.js` смотрит на `window.STAROSTA_API`. Пусто — режим «только это устройство» (как сейчас).
Когда сервер появится, в `index.html` добавится одна строка с адресом (`/api`, если сервер отдаёт и само приложение).
Так одна и та же версия приложения работает и локально (`Открыть на компьютере.bat`), и на сайте.

  (тем же, что в браузере). Разложим по таблицам, когда понадобятся ответы студентов и отчёты по многим группам.
- **Кабинета студента.** Сначала — староста и зам. Студенты — через Telegram-бота (`automation.md`).
- **Чтения почты через Gmail API.** Нужна платная проверка безопасности Google; IMAP с паролем приложения проще.

# Письма преподавателей → приложение

Цель (слова пользователя): «староста при заходе на сайт мог подключить свою почту, и то, что преподаватели
скидывают на почту, отправлялось ему на сайт, а не в общий доступ».

Первое подключение удобнее проверить через общий ящик по IMAP. Адрес на своём домене требует доверенного шлюза.
Шаги подключения и проверки описаны в [README сервера](../README.md#подключение-интеграций-на-тестовой-группе).

## Три способа подключить почту

| | Способ | Пароль почты | Работает с | Сложность для нас |
|---|---|---|---|---|
| **1** | **Пересылка на адрес группы** (основной) | не нужен | любая почта с правилами пересылки | свой домен + MX-запись |
| 2 | IMAP с паролем приложения | пароль приложения (не основной), шифруем | Яндекс, Mail.ru, Gmail, почта вуза | хранение секрета |
| 3 | IMAP через Яндекс ID (OAuth, `mail:imap_ro`) | не нужен | только Яндекс | регистрация приложения в Яндекс OAuth |
| ✗ | Gmail API | — | Gmail | **не делаем**: доступ к письмам — restricted scope, для публичного сервиса нужна платная проверка Google |

### 1. Прямой адрес и пересылка через шлюз

1. У каждой группы при создании появляется адрес: `<код>@in.<домен>`, например `26-ivt-2-1-a3f9c1@in.starosta.ru`.
   Код состоит из названия группы латиницей и случайного суффикса.
2. Преподаватели могут писать прямо на этот адрес. Для писем в другом ящике его владелец настраивает
   переадресацию по списку отправителей. Если провайдер требует подтверждение, обработайте его на шлюзе.
3. Шлюз проверяет отправителя и передаёт исходное письмо в защищённый HTTPS-обработчик приложения.

Где правило в разных почтах:
- **Яндекс**: Настройки → Правила обработки писем → Создать правило → «Переслать по адресу» (просит пароль от почты и подтверждение).
- **Mail.ru**: Настройки → Фильтры → Добавить фильтр → «Переслать копию» (подтверждение по ссылке в письме).
- **Gmail**: Настройки → Пересылка и POP/IMAP → Добавить адрес (код подтверждения) → Фильтры: «От» → «Переслать».
- **Почта вуза** (если есть): обычно Outlook/Exchange — «Правила для входящих» → «Перенаправить».

Что нужно для запуска: домен, MX-запись на доверенный шлюз и общий секрет шлюза и API.
Закрытый SMTP-приёмник для своего шлюза доступен отдельным профилем Compose.

### 2–3. IMAP (второй шаг)

`imap.py`: подключение по TLS (993), `SELECT INBOX` только для чтения. Сервер проверяет заголовок отправителя
новых писем, начиная с последнего UID, и загружает тело только у писем известных преподавателей. `BODY.PEEK`
сохраняет статус прочтения. Сбой загрузки оставляет письмо для следующей проверки (`worker.py`).
Пароль приложения шифруется (`security.encrypt_secret`) и никогда не отдаётся обратно в приложение.

## Что происходит с письмом

```
письмо → parse_email → от преподавателя группы? ──нет──► не сохраняем
                              │ да
                              ▼
         уже было (тот же Message-ID)? ──да──► пропускаем
                              │ нет
                              ▼
   MailMessage (текст, вложения, срок хранения 60 дней) + InboxItem (предложение)
                              ▼
            экран «Почта»: староста принимает или отклоняет
```

**Преподаватель** определяется по полю «Почта» в карточке преподавателя (оно уже есть в приложении), можно
несколько адресов через запятую. Регистр, `+метки`, `ya.ru`/`yandex.ru`, точки в Gmail не мешают (`normalize_addr`).

**Предложение** (`suggest`):
- тип — по словам в теме и тексте: перенос/отмена пары → «Изменение в расписании»; экзамен/зачёт/консультация →
  «Сессия»; лабораторная/отчёт/сдать → «Сдача работы»; собрание/мероприятие → «Событие»; иначе «Объявление»;
- срок — даты «15.11», «15.11.2026», «20 ноября», «к пятнице», «до понедельника», «завтра»; дата со словами
  «до / к / срок / сдать» важнее остальных;
- предмет — первый предмет из карточки преподавателя;
- заголовок — тема письма без «Re:/Fwd:».

**Ничего не создаётся само.** Староста видит письмо и предложение и решает: «Сделать сдачей / делом / событием»,
«Перенести в журнале», «В чат» (по шаблону сообщений) или «Отклонить». Объект создаёт приложение в данных группы,
серверу отправляется только отметка «принято: works/w123».

## Вложения

Сохраняем PDF, DOCX, XLSX, изображения до 10 МБ на 60 дней в S3-совместимом хранилище в РФ (Yandex Object Storage,
Selectel). В приложении — кнопка «Открыть» с временной ссылкой. **Пока не сделано** (`service.py`, TODO шаг 6).

# Автоматизация: что приложение может делать за старосту

Собрано из всего, что обсуждали (2026-11-05…06). Отмечено, что уже работает без сервера и что требует сервера.

## Уже работает (без сервера)

| Что | Как |
|---|---|
| Расписание | Загрузка с сайта НГТУ (`my-api.nntu.ru`), автопроверка изменений, переносы и замены |
| Посещаемость | Отметка в одно касание, «Все были», больничные отмечаются «У» сами, итоги, риск недопуска |
| Списки для чата | Отсутствующие, должники, кто не ответил — столбиком с номерами |
| Шаблоны сообщений | 19 подстановок: `{отсутствующие}`, `{не_сдали_работу}`, `{расписание_завтра}`… |
| Контакты | Вставка таблицы, ответы Google Формы, .xlsx/.csv/.vcf → телефоны, почты, дни рождения |
| Напоминания на ПК | За 10 мин до пары, «отметьте посещаемость», утренняя сводка — пока вкладка открыта |
| Сборы, сдачи, документы, опросы, оценки | Отметки «кто сдал», суммы, должники, стипендия |

## Требует сервера — по порядку

### 1. Письма преподавателей → предложения (`mail.md`) — шаги 5–7
Письмо → «Сделать сдачей до 15.11» → одно нажатие. Далее: перенос пары из письма прямо в журнал.

### 2. Напоминания, когда приложение закрыто (Web Push) — шаг 8
- Сервер хранит подписку браузера (`PushSubscription`) и шлёт пуш через VAPID — работает в Chrome, Edge,
  Firefox, Safari на iOS 16.4+ (если приложение добавлено на главный экран).
- Те же напоминания, что сейчас на ПК (`reminderDigest`), но считает их `worker.py`.
- Новое письмо преподавателя → пуш «Смирнов: Лабораторная №3, до 15.11».

### 3. Telegram-бот группы — шаг 9
Один бот на всех старост (`@starosta_nntu_bot`), группа подключается кодом из приложения.
- **Сбор контактов**: студент пишет боту `/start <код группы>` → бот спрашивает ФИО, телефон, день рождения
  (с согласием) → данные приходят старосте на подтверждение (сейчас это делается вставкой таблицы).
- **Опросы с ответами самих студентов**: опрос из приложения → бот рассылает → ответы сами появляются
  в опросе (сейчас староста отмечает ответы вручную).
- **Самоотметка на паре**: староста показывает код/QR на 2 минуты → студенты отмечаются в боте →
  староста подтверждает (защита от «отметь за друга» — код меняется, только во время пары).
- **Рассылки**: «Расписание на завтра» каждый вечер, напоминание должникам по сдачам и сборам (по шаблону).
- Технически: Telegram Bot API через вебхук на наш сервер; Telegram — иностранный сервис, поэтому через бот
  передаём минимум (без телефонов и оценок в сообщениях), а хранение — у нас в РФ.

### 4. Общий доступ — шаг 4
Зам видит и отмечает то же, что староста (приглашение кодом). Позже: куратор только смотрит итоги.

### 5. Отчёты и выгрузки — после запуска
- Ведомость посещаемости в Excel за период (уже есть для ПК) — автоматически раз в месяц на почту старосты.
- «Итоги семестра» для деканата.

### 6. Для многих групп — после запуска
- Каталог групп НГТУ: при регистрации выбор группы из расписания вуза (`nntu.js` уже умеет искать группы).
- Счётчик старост и групп (без персональных данных) — для портфолио и проверки спроса.
- Форма отзывов уже есть (Google Форма); позже — свой экран «Предложить идею».

## Правило для всей автоматизации

Автоматика **предлагает**, староста **подтверждает** — особенно всё, что уходит людям (рассылки, напоминания
должникам) и что меняет журнал. Исключение — то, что староста сам включил «всегда» (например, вечерняя рассылка расписания).

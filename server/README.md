# Сервер «Помощника старосты» — черновик

**Статус: фундамент, к приложению не подключён.** Приложение по-прежнему работает без сервера.
Здесь — всё, чтобы шаг за шагом добавить аккаунты, синхронизацию и письма преподавателей (план — `../ROADMAP.md`).

Что уже есть и проверено тестами:
- аккаунты: регистрация, вход по логину или почте, выход, сброс пароля, защита от подбора;
- группы: создание с переносом данных с устройства, синхронизация `data.json` с версиями и конфликтами,
  приглашение зама по коду;
- почта: адрес пересылки у каждой группы, подключение ящика по IMAP (пароль шифруется), фильтр
  «только от преподавателей группы», разбор писем (даты, тип, предмет), экран «Почта» (принять/отклонить).

## Запуск на своём компьютере

Нужен Python 3.11+. Из папки `server`:

```
python -m venv .venv
.venv\Scripts\activate            (Windows; на macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env            (и поменять STAROSTA_SECRET_KEY)
uvicorn app.main:app --reload --port 8000
```

Документация API с кнопкой «Попробовать»: http://127.0.0.1:8000/docs

## Тесты

```
python -m unittest discover -s tests -t . -v
```

- `tests/test_parse.py` — разбор писем; работает даже без установки библиотек.
- `tests/test_api.py` — весь путь: регистрация → группа → синхронизация и конфликт → письмо преподавателя и
  чужое письмо → «Почта» → приглашение зама. База — временный файл, настоящие данные не трогаются.

После изменения таблиц или API обновить документы: `python tools/export_contract.py`.

## На сервере

`docker-compose.yml`: PostgreSQL, API, `worker` (IMAP и очистка), `inbound` (приём писем на 25 порту), Caddy (HTTPS).
Перед первым запуском: VPS в России, домен, MX-запись для `in.<домен>`, файл `.env` (см. `.env.example`),
`DB_PASSWORD`. Подробно — шаг 2 в `../ROADMAP.md`.

# Помощник старосты

Приложение для старост групп разных вузов: расписание, посещаемость и дела группы.
Работает в браузере на телефоне и компьютере, можно установить как приложение (иконка на главном экране)
и пользоваться без интернета.

Без аккаунта данные хранятся только в браузере. В аккаунте данные выбранной группы сохраняются также
на локальном сервере и синхронизируются между устройствами с доступом к группе.

## Что где лежит
```
app for starosta/
├─ index.html                  — страница приложения
├─ css/                        — оформление (tokens.css — цвета и размеры, app.css — компоненты)
├─ js/
│  ├─ app.js                   — всё приложение: экраны, данные, отметки
│  ├─ nntu.js                  — загрузка расписания с сайта НГТУ
│  ├─ xlsx.js                  — выгрузка ведомости в Excel
│  ├─ api.js                   — клиент API и синхронизация групп
│  └─ config.js                — адрес локального API (для публикации нужна своя конфигурация)
├─ assets/                     — облегчённые шрифты (woff2), значок приложения
├─ demo/group.json             — пример для гостей: вымышленные студенты, расписание группы 26-ИВТ-2-1
├─ manifest.webmanifest, sw.js — установка и работа без интернета
├─ tools/                      — исходные шрифты и скрипт, который собирает из них облегчённые
├─ tests/                      — автотесты в браузере: python tests/run.py (подробнее в tests/README.md)
├─ server/                     — API аккаунтов, групп и почты; локальный запуск через dev_local.py
├─ prototypes/                 — макеты входа и почты, не входят в приложение
├─ Открыть на компьютере.bat   — запустить у себя на ПК
└─ docs/                       — личное: документы, старые выгрузки, архив программы для ПК (не публикуется)
```

Сейчас приложение работает **только на этом компьютере**: «Открыть с аккаунтом.bat» → http://127.0.0.1:8765/
(пример — http://127.0.0.1:8765/#demo). Публичный сайт на GitHub Pages отключён 05.11.2026.

Для просмотра преподавателем опубликована отдельная [демонстрация группы 26-ИВТ-2-1](https://ego1sto666.github.io/starosta-helper-preview/#demo)
из [чистого репозитория](https://github.com/ego1sto666/starosta-helper-preview). В ней нет сервера, аккаунтов,
почты и личных файлов проекта; изменения демонстрационных данных сохраняются только в браузере посетителя.
ФИО 37 студентов, включая старосту Юнусова Артёма и заместителя, взяты из выгрузки состава группы; контактов нет.
Расписание группы основано на открытых данных НГТУ. Посещаемость, дела, сдачи, сборы, документы, опросы и оценки
случайные, не отражают реальную успеваемость студентов.
Повторное открытие ссылки в демонстрационной версии создаёт новый случайный набор.
При обновлении версии старая демонстрационная копия в браузере заменяется новым составом и на адресе `#home`.
Исходный репозиторий и его GitHub Pages в публикации не участвуют. Сборка с частной выгрузкой состава:
`python tools/build_teacher_preview.py dist/teacher-preview "docs/старые выгрузки/посещаемость_1сем_2026-11-03.csv"`.

## Пример для гостей
На стартовом экране — «Открыть пример» (или ссылка с `#demo`): загружается `demo/group.json` — вымышленные студенты
и преподаватели с расписанием группы 26-ИВТ-2-1. Посещаемость с начала занятий по сегодня,
дела, сдачи, сборы, сессия и событие расставляются случайно при каждом открытии. На всех экранах видна плашка
«Пример… отметки расставлены случайно» с кнопкой «Своя группа» (стирает пример). Если в браузере уже есть свои данные,
пример молча их не заменяет — сначала спрашивает.

**Оценки сайта** — анонимная Google Форма https://forms.gle/VsF3DQgE2heuuHsg7 (без имени и почты).
Ссылка — в константе `FEEDBACK_URL` в начале `js/app.js`; кнопки «Оценить» есть на плашке примера,
на стартовом экране и в настройках. Если константу очистить, кнопки пропадут.

## Запуск на компьютере
**«Открыть на компьютере.bat»** запускает только сайт: без сервера аккаунт и почта недоступны.
Для регистрации и почты сначала установите зависимости в `server/.venv` по `server/README.md`, затем
запустите `.\server\.venv\Scripts\python.exe .\server\dev_local.py` из корня проекта (на этом компьютере также
есть удобный файл **«Открыть с аккаунтом.bat»**). Скрипт запускает сайт, API и проверку почты только на `127.0.0.1`.
При первом запуске создаётся `server/.env` со случайным секретным ключом; файл и база `server/dev.db`
не попадают в Git. Остановите запуск закрытием окна или `Ctrl+C`.

Зарегистрируйтесь в «Настройки → Аккаунт старосты», создайте группу, указав свой вуз. Если группа уже
заполнена в этом браузере, отметьте «Перенести данные». У каждой группы свои данные и входящие письма.
Новую пустую группу встречает мастер: вуз и название → состав → расписание → проверка. Без аккаунта он
открывается кнопкой «Начать настройку» на стартовом экране. Каждый шаг можно пропустить; мастер доступен
повторно в настройках.
В «Настройки → Почта преподавателей» укажите почту и **пароль приложения** от почтового сервиса.
Добавьте адреса преподавателей в карточках преподавателей. Локальная проверка ящика выполняется раз в 2 минуты,
пока окно запуска открыто. Адрес пересылки `*.local` пока тестовый и внешние письма не принимает.

Данные привязаны к адресу сайта. Открытое по `127.0.0.1:8765` и открытое по ссылке в интернете —
два разных хранилища. Переносить данные между ними — через «Скачать копию» и «Загрузить из файла» в настройках.

## Что умеет
- **Сегодня** — пара, которая идёт сейчас, кнопка «Отметить посещаемость», сроки, события, дни рождения.
- **Журнал** — расписание и отметки на одном экране: неделя с днями, пары дня по времени, звонки.
  Нажатие на пару — сразу к отметке посещаемости; «⋯» на карточке — перенести, отменить, изменить в расписании.
  Пары по неделям (чётные/нечётные) в пределах **периода занятий** — первый и последний день семестра
  и чётность текущей недели задаются в настройках; своё время у пары, пара не по расписанию.
- **Расписание НГТУ** — по номеру группы (например, `26-ИВТ-2-1`) пары, аудитории, преподаватели и звонки
  подтягиваются с открытого сайта НГТУ. Перед заменой показывается, что изменится; отметки в журнале сохраняются.
- **Импорт для любого вуза** — «Настройки → Импорт состава/расписания» или мастер. Состав из `.xlsx`, `.csv`,
  `.vcf` либо вставленной таблицы: ФИО, контакты и подгруппа, с предпросмотром. Расписание из `.xlsx`,
  `.csv`, `.tsv`, `.txt` либо вставленной таблицы с заголовками «День»/«Дата», «Пара»/«Время», «Предмет»;
  необязательные колонки — неделя, тип, аудитория, преподаватель, подгруппа. Строки с датой становятся
  разовыми парами. Повторная загрузка обновляет найденную пару по дню, номеру, неделе и предмету,
  сохраняя её идентификатор и прежние отметки; отсутствующие в файле пары не удаляются.
- **Автопроверка** — раз в день при открытии приложение сверяет ближайшие две недели с сайтом НГТУ и предлагает
  принять переносы, отмены, новые пары и замены аудиторий (только на эти дни). Ручные изменения старосты не трогает.
- **Переносы и отмены** — кнопка «⋯» на паре в журнале: перенести на другой день или пару, отменить в этот день,
  вернуть. **Пара не по расписанию** — разовая пара на конкретную дату (кнопка «+» в журнале).
- **Журнал** — отметка в одно касание (+ / Н / У), «Все были», копирование списка отсутствующих,
  внеплановые занятия, подгруппы.
- **Итоги** — за весь период занятий или за выбранный месяц: кольцо посещаемости и «в среднем на паре X из Y»,
  линия по неделям с порогами 85 и 70 %, таблица «Дни и пары» (где посещаемость ниже), состав отметок по предметам,
  студенты с засечкой порога риска; у студента — пунктир «в среднем по группе» и засечки группы по предметам.
  Выгрузка ведомости в Excel (лист «Сводка» и лист на каждый предмет). Уважительные пропуски не снижают процент.
- **Группа** — студенты (телефон, почта, Telegram), роли (староста, замы), подгруппы, преподаватели с контактами.
- **Карточка студента** — пропуски по месяцам: последний раскрыт, остальные открываются нажатием. Все записи доступны без ограничения 20 строк.
- **Аккаунт** — регистрация, вход, отдельные группы для разных вузов и синхронизация данных через локальный сервер.
  Без аккаунта данные остаются в браузере. Локальная регистрация показывает информационную страницу о данных;
  перед публичным запуском нужна полноценная политика обработки персональных данных.
- **Академ и отчисление** — в карточке студента, с датой и приказом. С этой даты студента нет в отметках, сдачах
  и сборах, прошлые отметки остаются в журнале, итогах и Excel. В «Группе» — отдельные разделы; «Вышел из академа» /
  «Восстановить» возвращает в списки, прошлый период сохраняется в истории.
  **Добавить списком** — вставить из чата, Word или Excel либо выбрать файл `.xlsx`/`.csv`: номера, лишние столбцы
  и повторы убираются, уже записанные пропускаются (никто не удаляется).
  **Подгруппы списками** — отдельный список на каждую подгруппу, для основного деления или для своего у предмета;
  хватает фамилии, если она в группе одна. Перед сохранением видно, кто не найден и кто остался без подгруппы.
  В «Группа → Подгруппы» можно задать от 2 до 9 основных подгрупп и отдельное количество для любого предмета,
  даже если его ещё нет в расписании. При уменьшении числа сначала переведите студентов из лишних подгрупп.
- **Дни рождения** — указываются в карточке студента (`ДД.ММ` или `ДД.ММ.ГГГГ`). За неделю и в сам день
  при открытии приложения всплывает напоминание («Понятно» / «Напомнить завтра»), в день рождения на главной —
  карточка с кнопкой «Поздравление» (текст для чата группы копируется в буфер). С годом рождения видно, сколько исполнится.
- **Учёба** (`#study`) — три вкладки:
  - *Сдачи* — кто сдал лабораторную или реферат (с учётом подгруппы), «Все сдали», список должников для чата;
  - *Сессия* — экзамены, зачёты, консультации; ближайший — с обратным отсчётом на главной;
  - *Оценки* — ведомость по каждому экзамену и зачёту (5/4/3/2, зач/незач, н/я), пересдачи, долги,
    кто остаётся без стипендии (долг, тройка или пересдача — подсказка, правила вуза могут отличаться).
- **Внеучебка** (`#tasks`) — четыре вкладки:
  - *Дела* — дедлайны, объявления, напоминания (профком, собрания);
  - *Сборы* — два списка: *Деньги* (сумма с человека, кто сдал, сколько собрано) и *Документы* в деканат
    (086/у, флюорография, согласия, заявления): кто сдал, должники для чата;
  - *События* — мероприятия группы с отметкой «кто идёт»;
  - *Опросы* — вопрос и варианты: текст опроса копируется в чат, ответы староста отмечает сам, видно, кто не ответил.
- **Шаблоны сообщений** (`#templates`) — свои заготовки для чата и преподавателей; `{отсутствующие}`, `{не_сдали_работу}`,
  `{расписание_завтра}` и ещё 16 слов подставляются из журнала, сдач, сборов и расписания.
- **Контакты списком** — «Группа» → значок контакта: вставить таблицу (Excel, Google Таблицы, ответы Google Формы)
  или загрузить .xlsx, .csv, контакты телефона .vcf. Столбцы узнаются по заголовкам или по виду данных,
  студенты — по ФИО; заполняются телефон, почта, Telegram, день рождения (уже заполненное не трогаем, если не попросить).
- **Фото одногруппников** — нажмите на кружок с инициалами в карточке студента. Фото всей группы разом — «Контакты списком» → «Фото группы»
  (файлы, названные по фамилии: «Иванов.jpg»). Фото уменьшается до 160 px и хранится вместе с данными.
- **Списки для чата** (должники, отсутствующие, кто не ответил) копируются столбиком, с номерами.
- **Напоминания на этом компьютере** — в настройках: за 10 минут до пары, «отметьте посещаемость» через 5 минут после начала,
  утром — сроки, сессия и дни рождения. Работают, пока приложение открыто в браузере (без сервера).
- **Больничные** — в карточке студента: даты (все пары в эти дни — «У», уже поставленные «Н» исправляются),
  заметка и фото справки (хранится в IndexedDB только на устройстве, в копию данных не входит).
- **Риск недопуска** — студенты, у которых посещаемость по предмету ниже порога (по умолчанию 70 %, меняется в настройках).
- **Тексты для чата** — расписание дня, изменения с сайта НГТУ, должники, расписание сессии, поздравления.
- **Код-пароль** — экран с цифрами при открытии и после 5 минут в фоне (защита от посторонних глаз, не шифрование).
- **Быстрые действия** — долгое нажатие на иконку установленного приложения: «Отметить текущую пару» (`#now`),
  «Сдачи работ», «Журнал».
- **Настройки** — тема (светлая, фиолетовая, тёмная; пока не выбрана вручную — как в системе), период занятий, звонки, копия данных, установка.

## Данные
- Хранятся в `localStorage` браузера под ключом `starosta.data` в том же формате, что был у программы на ПК
  (`data.json`), поэтому старый файл `%APPDATA%\starosta\data.json` можно просто загрузить.
- Изменения на даты: `overrides` (`"ГГГГ-ММ-ДД|id пары"` → отмена, перенос, замена аудитории/преподавателя)
  и `oneoff` (разовые и перенесённые пары). Поле `src` — кто изменил: `manual` (староста) или `nntu` (автопроверка).
- Если отметки есть, а копию не скачивали больше 14 дней, на главной появится напоминание.
- Браузер просят не удалять данные при нехватке места (`navigator.storage.persist`).

## Расписание НГТУ
Берётся с адреса `https://my-api.nntu.ru/lesson-schedule/public` (без входа; его же использует проект
NNTU-Map). Официальной документации нет: если НГТУ поменяет формат, правится разбор в `js/nntu.js`.
Сайт отдаёт только текущую и следующую неделю: пара, которая есть в обеих, идёт «каждую неделю»,
в одной — по её чётности. Разовые переносы попадают в расписание как постоянные.

## Дальше: публикация и автоматизация
Локально работают регистрация, группы, синхронизация и чтение писем по IMAP. Перед публикацией нужны домен,
развёртывание сервера, полноценная политика обработки данных, рабочий сброс пароля и проверка безопасности.
Адрес пересылки начнёт работать после настройки почтового домена и MX-записи. План — `ROADMAP.md`.

## Оформление и шрифты
- Текст — **Onest** (сделан под кириллицу), крупные цифры и приветствие — **Unbounded**. Оба переменные:
  любая толщина в одном файле, кириллица и латиница — отдельными файлами в `assets/`.
- Значки — **Phosphor Icons**: тонкие линии, у активного пункта меню — залитые. Из полного набора (0,5 МБ)
  в `assets/icons.woff2` и `assets/icons-fill.woff2` попадают только значки из таблицы `ICON` в `js/app.js`, — по 6–8 КБ.
  Имена и коды значков — в `tools/fonts/phosphor-names.json`, все значки — на phosphoricons.com.
  Добавили значок — пересоберите:
```
pip install fonttools brotli
python tools/subset_fonts.py
```
- Смена экранов — плавный переход (View Transitions), листы выезжают снизу; при «Уменьшить движение» в системе анимации выключаются.

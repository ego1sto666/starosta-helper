# Тесты

Каждый тест — страница `tests/<имя>.html`. Она открывает приложение во фрейме, нажимает кнопки как пользователь
и пишет журнал шагов. Последняя строка журнала — `ERRORS: нет`, если на странице не было ошибок.

| Тест | Что проверяет |
|---|---|
| `import.html` | первый запуск, загрузка расписания НГТУ по группе, импорт данных, обновление расписания, Excel, копия, период занятий, звонки, удаление всех данных |
| `schedule-lists.html` | автопроверка расписания, переносы и отмены, разовые пары, списки группы (текст и `.xlsx`), подгруппы списками |
| `birthdays.html` | напоминания о днях рождения: за неделю, в сам день, «Понятно» и «Напомнить завтра» |
| `demo.html` | пример для гостей: вымышленные имена, случайные отметки, плашка на экранах, выход, ссылка `#demo`, свои данные не заменяются |
| `features.html` | сдачи работ, сборы, сессия, больничные, риск недопуска, тексты для чата, `#now`, код-пароль, контакты и фото |
| `sync-merge.html` | слияние изменений в черновом клиенте API; к сайту пока не подключён |
| `topbar.html` | шапка при прокрутке и смене темы на телефоне и компьютере |

## Запуск

```
python tests/run.py            # все тесты, результат в консоли и в tests/out/
python tests/run.py features   # один тест
```

Нужны Chrome и интернет: часть тестов обращается к открытому API расписания НГТУ.
Можно открыть тест и в обычном браузере: `python tests/server.py`, затем `http://127.0.0.1:8770/__t/import.html`.

## Данные

`fixtures/demo.json` — обезличенный набор: расписание группы 26-ИВТ-2-1 (оно открыто на сайте НГТУ)
с вымышленными именами студентов и преподавателей, без телефонов и дней рождения. `fixtures/list.xlsx` — список группы, сохранённый в Excel,
для проверки загрузки из файла. Тесты и пример для гостей используют вымышленные имена. Личные данные из `docs/` в тесты и пример не попадают.
